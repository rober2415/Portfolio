SURL - URL Shortener

Desarrollé la aplicación para resolver el problema de la gestión e interacción con enlaces largos, buscando ofrecer una herramienta rápida, ligera y escalable. La aplicación fue construida con Angular, haciendo uso de módulos y lazy loading para mejorar el rendimiento del cliente. Por su parte, la comunicación con el backend cuenta con protección de rutas y autenticación mediante Laravel Sanctum.
